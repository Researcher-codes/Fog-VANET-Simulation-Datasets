# Security-Driven Routing in Fog-Enabled VANETs for Optimizing QoS and Energy Efficiency

## Overview
This repository contains the datasets used in the experimental evaluation of the paper **"Security-Driven Routing in Fog-Enabled VANETs for Optimizing QoS and Energy Efficiency."** The provided data support the simulation, routing, QoS analysis, load balancing, and node classification experiments reported in the manuscript.

## Repository Contents

- `route_records.mat` – MATLAB dataset containing routing records.
- `route_records_with_cleaned_data.xlsx` – Cleaned routing and QoS dataset.
- `route_records_with_hypothetical_data.xlsx` – Extended dataset used for simulation and performance analysis.
- `updated_fog_node_packet_count.mat` – MATLAB dataset containing fog node packet count information used in load-balancing analysis.
